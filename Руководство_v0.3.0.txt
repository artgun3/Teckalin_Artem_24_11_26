РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ
Приложение «Приём заявок»
Версия программы: для версии 0.3.0

1. НАЗНАЧЕНИЕ ПРОГРАММЫ
Приложение «Приём заявок» предназначено для учёта поступающих заявок, отслеживания их статуса и контроля количества закрытых заявок. Максимальное количество одновременно учитываемых заявок — 10.

2. ЗАПУСК И ВНЕШНИЙ ВИД ОКНА
Для запуска программы откройте файл «app_v03_обновление.py».
В терминале введите команду python app_v03_обновление.py
В верхней строке заголовка окна отображается название «Приём заявок 0.3.0», а в нижней части окна указана актуальная версия: «Версия 0.3.0».
В окне расположены:
- логотип компании;
- счётчик «Количество заявок:» (по умолчанию «0»);
- строка даты и времени последнего приёма («Принято: —»);
- текущий статус («Статус: Новая»);
- счётчик выполненных заявок («Закрыто заявок: 0»);
- кнопки управления: «Сменить статус», «Принять заявку», «Сбросить».

3. КАК ПРИНЯТЬ ЗАЯВКУ
Нажмите кнопку «Принять заявку».
- Счётчик «Количество заявок» увеличится на 1.
- В строке «Принято:» автоматически отобразятся текущие дата и время.
- При достижении 10 заявок появится надпись «Лимит: 10», а кнопка «Принять заявку» станет неактивной.

4. КАК СМЕНИТЬ СТАТУС И УЧИТЫВАТЬ ЗАКРЫТЫЕ ЗАЯВКИ
Для изменения состояния заявки нажимайте кнопку «Сменить статус». Статусы переключаются по кругу:
«Новая» → «В работе» → «Готово» → «Новая».
- Когда статус переходит в значение «Готово», счётчик «Закрыто заявок:» автоматически увеличивается на 1.

5. СБРОС ДАННЫХ
Для начала новой смены или очистки всех показателей нажмите кнопку «Сбросить».
После нажатия:
- «Количество заявок» обнуляется до «0»;
- счётчик «Закрыто заявок:» сбрасывается до «0»;
- дата принятия возвращается в состояние «Принято: —»;
- кнопка «Принять заявку» снова становится активной.
